# Security Policy

## Scope

This project is a local web-scraping and data-export tool. Security reports may cover code execution, dependency issues, unsafe handling of local files, credential or secret exposure, and vulnerabilities in the repository's automation.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's **Report a vulnerability** button for this repository. If private reporting is not enabled, contact the repository maintainers through a private channel before opening an issue.

Do not publish exploit details, credentials, cookies, private URLs, or personal data in a public issue or pull request.

Include, when safe to share:

- affected version or commit;
- operating system and Python version;
- reproduction steps or a minimal proof of concept;
- likely impact; and
- any suggested mitigation.

You will receive an acknowledgement when the report is reviewed. Please allow maintainers reasonable time to investigate and release a fix before public disclosure.

## Dependency updates

Dependabot is configured for the Python and GitHub Actions dependencies. Keep the lock-free version ranges and CI checks under review when updating them.
